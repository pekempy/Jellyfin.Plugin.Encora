Title format variables

Every Title Format field on the Movie/TV/Audio tabs has its own click-to-insert palette showing exactly which of these apply to it. Every value comes from the Encora recording that matched the file (or, for Series/Season/Artist, whichever file inside that folder was used to look it up).
VariableMaps toAvailable in
{show}Show name. If "Act 1"/"Act 2" etc. is detected in the filename, it's appended (Movies only).Movie, Series, Artist
{date}Long-form date, e.g. "December 31, 2024". Appends "(matinée)" and, for episodes/tracks, "(Act N)" automatically when detected.Movie, Episode, Album
{date_iso}ISO date, e.g. "2024-12-31"Movie, Episode, Album
{date_usa}US-order date, e.g. "12-31-2024"Movie, Episode, Album
{date_numeric}Day-first numeric date, e.g. "31-12-2024"Movie, Episode, Album
{tour}Tour nameMovie, Season, Album
{master}Name of the recording's master (whoever recorded/filmed it)Movie, Episode, Album
{venue}Venue nameMovie, Episode, Series, Season, Artist, Album
{city}CityMovie, Episode, Series, Season, Artist, Album
{act}Act number, only present when "Act N" is detected in the filenameTrack
Episode/Track titles don't have {show}/{tour} - those come from the Series/Season or Artist/Album instead.

Your API Key for StageMedia
Periodically re-checks items Encora has already matched, so subtitle/cast/NFT changes on Encora's side get picked up automatically. Set to 0 to turn this off. This runs as the "Refresh Encora Metadata" task under Dashboard → Scheduled Tasks → Encora - if you change the number here after it's already run once, either restart Jellyfin or edit the schedule directly there for the new interval to take effect.
Each video file is matched as a standalone recording.
